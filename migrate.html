구글시트(Apps Script) → Supabase 데이터 이관

이 페이지는 한 번만 쓰는 도구입니다. 이관이 끝나면 이 파일은 지워도 됩니다.
아래 값이 기본으로 채워져 있으면 그대로 "1) 구글시트에서 불러오기" → "2) Supabase로 밀어넣기" 순서로 누르면 됩니다. 



    

        참고: Supabase에 먼저 supabase/schema.sql을 SQL Editor에서 실행해서 테이블을 만들어둔 상태여야 합니다.

        이 파일을 더블클릭(file://)으로 열었을 때 요청이 막히면, 터미널에서 python3 -m http.server 실행 후
        http://localhost:8000/migrate.html로 열어보세요.
