# 특별실 예약 관리 웹앱

격자형 시간표 기반의 특별실 예약 관리 시스템입니다. 월~금 요일과 1~10교시로 구성된 시간표에서 예약을 생성, 수정, 삭제할 수 있습니다.

## 주요 기능

### 1. 특별실 관리
- **특별실 추가**: "+ 특별실 추가" 버튼을 클릭하여 새로운 특별실을 추가할 수 있습니다.
- **특별실 전환**: 상단 탭을 클릭하여 다른 특별실의 시간표를 볼 수 있습니다.
- **특별실 삭제**: 특별실 탭을 우클릭하면 삭제할 수 있습니다.

### 2. 시간표 예약
- **예약 생성**: 빈 칸(교시)을 클릭하면 예약 모달이 열립니다.
  - 예약자명 (필수)
  - 학급 (선택)
  - 목적 (선택)
  - 상태 선택 (확정/기본/대기)
- **예약 수정**: 예약된 칸을 클릭하면 수정 모달이 열립니다.
- **예약 삭제**: 예약 수정 모달에서 "삭제" 버튼을 클릭하면 예약을 삭제할 수 있습니다.

### 3. 예약 상태
- **확정 (●)**: 검정색 배경, 확정된 예약
- **기본 (◆)**: 회색 배경, 기본 예약
- **대기 (◎)**: 흰색 배경에 테두리, 대기 중인 예약

### 4. 날짜 네비게이션
- **주 단위 이동**: 좌우 화살표 버튼으로 이전/다음 주로 이동할 수 있습니다.
- **주 선택**: 드롭다운 메뉴에서 특정 주를 선택할 수 있습니다.
- 현재 주 기준으로 앞뒤 4주까지 선택 가능합니다.

### 5. 내예약보기
- "내예약보기" 버튼을 클릭하고 예약자명을 입력하면 해당 사용자의 모든 예약을 확인할 수 있습니다.
- 예약 목록에서 "보기" 버튼을 클릭하면 해당 예약으로 이동하고 수정할 수 있습니다.

### 6. 데이터 저장
- **로컬 스토리지**: 기본적으로 웹 브라우저의 로컬 스토리지에 데이터가 저장됩니다.
- **구글 스프레드시트 연동** (선택적):
  - "구글시트 설정" 버튼을 클릭하여 API 키와 스프레드시트 ID를 설정합니다.
  - "시트로 동기화" 버튼을 클릭하면 로컬 데이터를 구글 스프레드시트에 업로드합니다.

## 사용 방법

### 기본 사용
1. 웹 브라우저에서 `index.html` 파일을 엽니다.
2. 처음 실행 시 기본 특별실(과학실, 시청각실, 회의실)이 자동으로 생성됩니다.
3. 특별실 탭을 클릭하여 원하는 특별실을 선택합니다.
4. 시간표에서 빈 칸을 클릭하여 예약을 생성합니다.

### 구글 스프레드시트 연동 (선택적)

#### 1. Google Cloud Console 설정
1. [Google Cloud Console](https://console.cloud.google.com/)에 접속합니다.
2. 새 프로젝트를 생성하거나 기존 프로젝트를 선택합니다.
3. "API 및 서비스" > "라이브러리"로 이동합니다.
4. "Google Sheets API"를 검색하고 활성화합니다.
5. "API 및 서비스" > "사용자 인증 정보"로 이동합니다.
6. "사용자 인증 정보 만들기" > "API 키"를 선택하여 API 키를 생성합니다.

#### 2. 스프레드시트 준비
1. 새 Google 스프레드시트를 생성합니다.
2. 스프레드시트 URL에서 ID를 확인합니다.
   - 예: `https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit`
   - ID: `1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms`
3. 스프레드시트를 "링크가 있는 모든 사용자"로 공유 설정합니다 (읽기/쓰기 권한).

#### 3. 앱에서 설정
1. "구글시트 설정" 버튼을 클릭합니다.
2. 생성한 API 키와 스프레드시트 ID를 입력합니다.
3. "API 연동 활성화" 체크박스를 선택합니다.
4. "저장" 버튼을 클릭합니다.
5. "시트로 동기화" 버튼을 클릭하여 데이터를 업로드합니다.

## 파일 구조

```
특별실 예약관리/
├── index.html          # 메인 HTML 파일
├── styles.css          # 추가 스타일 (Tailwind는 CDN 사용)
├── js/
│   ├── app.js          # 메인 애플리케이션 로직
│   ├── storage.js      # 로컬 스토리지 관리
│   ├── googleSheets.js # 구글 스프레드시트 API 연동
│   └── utils.js        # 유틸리티 함수 (날짜, 시간 처리)
└── README.md           # 사용 설명서
```

## 기술 스택

- **HTML5**: 웹 페이지 구조
- **Tailwind CSS**: 스타일링 (CDN 사용)
- **Vanilla JavaScript (ES6+)**: 모든 기능 구현
- **LocalStorage API**: 로컬 데이터 저장
- **Google Sheets API v4**: 선택적 클라우드 저장소

## 주의사항

1. **로컬 스토리지 제한**: 브라우저별로 저장 용량 제한이 있습니다 (일반적으로 5-10MB).
2. **구글 스프레드시트 API**: 무료 사용량 제한이 있습니다. 대량의 데이터를 동기화할 때는 주의하세요.
3. **데이터 백업**: 중요한 데이터는 정기적으로 구글 스프레드시트로 동기화하여 백업하세요.
